# 🔐 Deadlock Prevention and Recovery Toolkit

A web-based interactive toolkit built using **Python (Flask)** and **HTML/JS frontend** to simulate, detect, and recover from **deadlock scenarios** in operating systems using the **Banker's Algorithm**.

---

## 📌 Features

- ✅ System initialization with custom available resources and max need matrix.
- 🔄 Request and release resources dynamically for each process.
- 🔍 Detect deadlock using Banker's algorithm.
- 🧠 Display safe sequence if no deadlock is detected.
- 🌐 Web-based UI for interactive learning.

---

## 🧠 Project Overview

This project helps simulate how Operating Systems manage resources to avoid deadlocks. It demonstrates:
- Deadlock Prevention (via request validation)
- Deadlock Detection (Banker's algorithm)
- Recovery (via manual release and re-check)
